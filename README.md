# Débouchage Toulon

Site Next.js 14 (App Router, TypeScript, Tailwind).

```bash
npm install
npm run dev
```

- Téléphone, délais et tarifs : `lib/config.ts` (seule source, jamais en dur dans les composants)
- Contenu des villes : `lib/data/villes.ts` — des services : `lib/data/services.ts`
- URL publique : variable `NEXT_PUBLIC_SITE_URL` (voir `.env.example`)
